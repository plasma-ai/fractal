## Continue Mode

This node was continued (`$CONTINUE_MODE` is `true`). Before the first
iteration, uncommitted changes under your node folder (`$NODE_DIR`) were
committed and every other uncommitted change was discarded, so you start from
the last committed state. The one exception is a worktree that held an
unfinished git operation: it was left as found, with nothing committed or
discarded, and this prompt's Git Pending Mode section names each operation still
unfinished. Rebuild context within the current assignment's read and write
boundaries: your own memory (`$MEMORY_DIR`), prior plans in `$PLANS_DIR`, and
relevant project wiki material (`$WIKI_DIR`) only where permitted. A frozen
subject remains the input; continuation does not authorize live source reads,
excluded context, or opening sealed message channels. If you spawned child nodes
previously, decide what to do with each (see the `fractal` skill's Continue mode
section).
